# 🇮🇹 ISA Universal Prompt Generator

Generatore automatico di prompt per la compilazione del **Quadro C** di tutti i **25 modelli ISA**.

## ✨ Funzionalità

- ✅ Supporta **25 modelli ISA** diversi
- ✅ Estrae automaticamente il codice ISA dal PDF
- ✅ Genera prompt **ESCLUSIVO per Quadro C**
- ✅ Gli altri quadri (A, B, D, E, F, H) sono gestiti dal consulente
- ✅ Include controlli di coerenza e checklist pre-invio
